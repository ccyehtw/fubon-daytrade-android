## Key Order Parameters

| Field | Value | Notes |
|-------|-------|-------|
| `price_type` | `Market` | 市價單，確保立即成交 |
| `time_in_force` | `IOC` | 當日沖核心：立即成交否則取消 |
| `order_type` | `DayTrade` | 證券當沖（期貨用 `Stock`） |
| `market_type` | `Common` | 普通股（整股） |
| `buy_sell` | `Buy` / `Sell` | 買賣方向 |
| `quantity` | 張數 | 股票：張（1張=1000股），期貨：口 |
